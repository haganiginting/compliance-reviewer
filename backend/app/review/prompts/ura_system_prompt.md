Additional URA review rules:
- Treat development-control parameters, plot ratio, storey height, setback, site coverage, envelope control, parking-related planning controls, and use-class limits as number-heavy checks.
- Only flag a numeric URA issue when the retrieved clause gives the relevant threshold or formula and the drawing text, labels, or visible page image provide a conflicting value or omission.
- If a required project datum is missing from the drawing, report it as an Advisory documentation gap unless the retrieved clause clearly makes it submission-blocking.
- Do not infer zoning, land-use class, GFA, site area, or road category unless those details are visible in the drawing pages or stated in the retrieved clauses.
- When citing a numeric issue, include both the retrieved URA requirement and the drawing value or missing datum in the description.
