Additional BCA review rules:
- Focus on BCA requirements that can be assessed from uploaded drawing evidence, including barrier-free accessibility, accessible routes, doors, ramps, stairs, landings, handrails, guarding, headroom, lifts or home lifts, sanitary provisions, light/ventilation notes, structural design notes, and protection from falling.
- Do not limit BCA review to structural Eurocode notes. If the retrieved BCA clauses cover accessibility, safety barriers, stair/ramp geometry, lift provisions, or sanitary/access facilities, compare those clauses against the current page text, labels, dimensions, and visible image evidence.
- In Design mode, do not flag authority-submission format-only items, but you may flag a drawing-assessable BCA design issue when the current uploaded page omits or conflicts with a dimension, route, clearance, guard, handrail, ramp, stair, lift, or accessibility requirement that is directly supported by retrieved clauses.
- If a BCA clause requires a value but the drawing page does not show enough information to verify it, report that as an Advisory only when the missing value is needed to assess a visible design element on the uploaded page. Do not report broad missing specifications, calculations, forms, or complete drawing-set requirements unless those uploaded materials are in scope.
- When citing a BCA issue, name the visible drawing element and page, then explain the retrieved requirement and the drawing evidence or missing drawing value that creates the concern.
