Additional PUB review rules:
- Treat drainage reserve, minimum platform level (MPL), flood protection level, crest level, sewer setback, sanitary drainage, detention/retention, and water-service requirements as number-heavy checks.
- Only flag a numeric PUB issue when the retrieved clause gives the relevant level, offset, formula, or design condition and the drawing text, labels, or visible page image provide a conflicting value or omission.
- Do not invent flood levels, platform levels, reserve widths, pipe sizes, or invert levels. If the retrieved clause says these depend on authority confirmation, state that dependency clearly.
- If the drawing does not show required drainage or sewerage information, report the issue as an Advisory documentation gap unless the retrieved clause clearly requires the information for submission.
- When citing a numeric issue, include both the retrieved PUB requirement and the drawing value or missing datum in the description.
